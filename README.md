# StockSense — ML-прогноз спроса и план закупок для онлайн-продавцов

Продавцы на Kaspi Магазине, Wildberries и Ozon теряют деньги двумя способами: товар **закончился** (упущенные продажи и падение в выдаче) или его **слишком много** (деньги заморожены на складе). StockSense решает обе проблемы:

1. Загружаете выгрузку продаж (`date, sku, qty, price`) и остатки (`sku, stock, lead_time_days, unit_cost`).
2. Получаете прогноз на 28 дней по каждому SKU, статус («Заказать сейчас / Скоро / Норма / Излишек»), точку заказа, страховой запас, количество к заказу, выручку под риском и замороженный капитал.
3. Скачиваете готовый заказ поставщику в CSV.

## ML
- **Глобальная модель** `HistGradientBoostingRegressor` (Poisson loss) на всех SKU сразу — работает даже для товаров с короткой историей.
- **Direct multi-horizon**: для каждой даты прогноза и горизонта 1..28 — отдельный пример, без накопления ошибки рекурсивного прогноза.
- Признаки: скользящие средние 7/28/91, тренд, сезонность по дню недели, доля дней без продаж, относительная цена, **календарь распродаж** (11.11, Black Friday, Новый год, 8 Марта).
- **Честный бэктест** на последних 28 днях: на демо-данных WAPE **34.0%** против 44.3% у среднего за 28 дней и 53.0% у «как на прошлой неделе» (**на 23% точнее** наивного прогноза).

## Логика запасов
- Страховой запас = z(уровень сервиса 95%) · σ · √(срок поставки)
- Точка заказа = прогнозный спрос за срок поставки + страховой запас
- Количество к заказу = спрос за (срок поставки + 14 дней) + страховой запас − остаток
- ABC-анализ по выручке за 90 дней

## Монетизация (B2B SaaS)
| Тариф | Цена | Для кого |
|---|---|---|
| Start | 9 900 ₸/мес | до 100 SKU, загрузка CSV |
| Business | 29 900 ₸/мес | до 2 000 SKU, автоимпорт из Kaspi/WB API, Telegram-алерты «товар заканчивается» |
| Enterprise | от 150 000 ₸/мес | сети магазинов, интеграция с 1С/МойСклад |

**Почему за это платят:** один предотвращённый дефицит топового товара окупает подписку на год. На демо-магазине сервис показывает ~1 млн ₸ выручки под риском.

**Как продавать:** чаты и сообщества продавцов Kaspi/WB, бесплатный аудит склада («пришлите выгрузку — покажу, где вы теряете деньги»), партнёрство с фулфилмент-складами, курсы для селлеров.
